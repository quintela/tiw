# Review Priorities

Prioritize your feedback in this order:

1. **Critical Issues**: Bugs, security vulnerabilities, or serious performance problems that must be fixed.
2. **Major Improvements**: Architectural issues, significant performance optimizations, or important edge cases.
3. **Minor Improvements**: Code style, readability, and small optimizations.

For each issue:
- Clearly describe what the problem is
- Explain why it's a problem
- Suggest a specific solution when possible
- Include code examples for complex fixes
