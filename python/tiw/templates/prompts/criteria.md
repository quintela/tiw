# Review Criteria

Focus on these criteria during your review:

## Correctness
- Does the code work as intended?
- Are there any obvious bugs or errors?
- Are edge cases properly handled?

## Security
- Are there any security vulnerabilities?
- Is user input properly validated and sanitized?
- Are there potential issues with authentication, authorization, or data protection?

## Performance
- Are there any performance bottlenecks?
- Could any operations be optimized?
- Are there inefficient algorithms or data structures?

## Code Style
- Does the code follow best practices for the language/framework?
- Is the code readable and well-organized?
- Is the naming clear and consistent?

## Architecture
- Does the design make sense?
- Are there any separation of concerns issues?
- Could the code be better structured?

## Tests
- Are there appropriate tests?
- Is test coverage adequate?
- Are edge cases tested?
